# Citation checks (2026-10-01; sentence-level audit 2026-10-03 in citation_audit.md)

The sentence-level audit re-fetched all 44 sources and checked each of the 21 citing sentences as
written; three were reworded as a result (hyper-connections/mHC widen the residual stream rather than
reading earlier layers directly, and only the dynamic variant is input-dependent; Zhu & Gupta is cited
for the cubic schedule only; CoFi's unit types vs ours).

Every reference in `references.bib` was drafted by an AI assistant and then checked against the
original source page (arXiv abstract and, where the claim needs it, the full text; GitHub README,
model card or blog). Quotes below are verbatim from the fetched source. Verdict = whether the source
supports the specific way the paper uses it. The architecture set (hyper-connections, mHC, MUDDFormer,
DenseFormer, Chinchilla, OLMo 2, ...) is in `citation_checks_architecture.md` (all 19 fetched and
supported; caveats applied: Chinchilla implies rather than states 20 tokens/param, Kaplan writes C = 6N per
token, MUDDFormer weights are per source layer per position, mHC projects only the residual-mixing matrix). Humans must still verify everything before submission.

## Pruning

- **zhu2017prune** (arXiv 1710.01878, Zhu & Gupta, 2017; no venue on the page). Claim: cubic gradual
  sparsity schedule during training. Section 3: "the sparsity is increased from an initial sparsity
  value s_i (usually 0) to a final sparsity value s_f over a span of n pruning steps" with
  s_t = s_f + (s_i - s_f)(1 - (t - t_0)/(n dt))^3; "allowing the network training steps to recover
  from any pruning-induced loss in accuracy". SUPPORTED.
- **michel2019heads** (arXiv 1905.10650, NeurIPS 2019). (a) "a large percentage of attention heads can
  be removed at test time without significantly impacting performance." (b) importance
  I_h = E_x |dL(x)/d xi_h| ("expected sensitivity of the model to the mask variables"), "equivalent to
  the Taylor expansion method from Molchanov et al. (2017)". SUPPORTED.
- **molchanov2019taylor** (arXiv 1906.10771, 2019; venue not on the page). First-order Taylor
  importance of a gated unit, I(1)_m(z) = (dE/dz_m)^2, "computed from parameter gradients readily
  available during standard training". PARTIALLY SUPPORTED: the criterion uses gradients and weights
  or gate gradients, not activations; the paper cites it for the gate-gradient Taylor criterion only.
- **xia2022cofi** (arXiv 2204.00408, ACL 2022). "jointly prune coarse-grained (e.g., layers) and
  fine-grained (e.g., heads and hidden units) modules, which controls the pruning decision of each
  parameter with masks of different granularity." SUPPORTED (also prunes hidden dimensions).
- **xia2023sheared** (arXiv 2310.06694; venue not on the page). "targeted structured pruning, which
  prunes a larger model to a specified target shape by removing layers, heads, and intermediate and
  hidden dimensions"; "requiring only 3% of compute compared to training such models from scratch".
  SUPPORTED.

## Evaluation and instruction tuning

- **zheng2023judge** (arXiv 2306.05685, NeurIPS 2023 Datasets and Benchmarks). "We create MT-bench, a
  benchmark consisting of 80 high-quality multi-turn questions." Eight categories: "writing, roleplay,
  extraction, reasoning, math, coding, knowledge I (STEM), and knowledge II (humanities/social
  science)." Position bias: "A conservative approach is to call a judge twice by swapping the order of
  two answers and only declare a win when an answer is preferred in both orders. If the results are
  inconsistent after swapping, we can call it a tie." Reference-guided judging: "we propose a
  reference-guided method, in which we first generate LLM judge's answer independently, and then
  display it as a reference answer in the judge prompt." Agreement: "strong LLM judges like GPT-4 can
  match both controlled and crowdsourced human preferences well, achieving over 80% agreement".
  SUPPORTED; which categories get reference answers (math, reasoning, coding) comes from the FastChat
  code, not the paper text.
- **gao2024lmeval** (Zenodo 10.5281/zenodo.12608602, v0.4.3, July 2024; README BibTeX title "The
  Language Model Evaluation Harness"). "a unified framework to test generative language models on a
  large number of different evaluation tasks." SUPPORTED. Author order follows the README BibTeX.
- **allal2025smollm2** (arXiv 2502.02737). "We additionally introduce new specialized datasets
  (FineMath, Stack-Edu, and SmolTalk)"; "we also trained two smaller models: SmolLM2-360M ... and
  SmolLM2-135M". smol-smoltalk card: "This is a subset of SmolTalk dataset adapted for smol models with
  less than 1B parameters. We used it to build SmolLM2-360M-Instruct and SmolLM2-135M-Instruct."
  SUPPORTED.
- **taori2023alpaca** (GitHub README). "fine-tuned from a 7B LLaMA model on 52K instruction-following
  data generated by the techniques in the Self-Instruct paper"; outputs "generated by text-davinci-003".
  yahma/alpaca-cleaned card: "a cleaned version of the original Alpaca Dataset released by Stanford"
  (51,760 rows). SUPPORTED.
- **conover2023dolly** (Databricks blog, 2023-04-12). "databricks-dolly-15k contains 15,000
  high-quality human-generated prompt / response pairs"; "authored by more than 5,000 Databricks
  employees". SUPPORTED.
- **yue2023mammoth** (arXiv 2309.05653; venue not on the page). "MathInstruct is compiled from 13 math
  datasets with intermediate rationales"; "encompasses 260K (instruction, response) pairs"; "a unique
  hybrid of chain-of-thought (CoT) and program-of-thought (PoT) rationales". SUPPORTED.
- **cobbe2021gsm8k** (arXiv 2110.14168). "we introduce GSM8K, a dataset of 8.5K high quality
  linguistically diverse grade school math word problems." SUPPORTED.
- **merity2016wikitext** (arXiv 1609.07843; venue not on the page). "we also introduce the freely
  available WikiText corpus"; "available in two different sizes: WikiText-2 and WikiText-103";
  articles "fitting the Good or Featured article criteria". SUPPORTED.
- **vig2020causal** (NeurIPS 2020 listing, 7 authors; the arXiv version 2004.12265 has a different
  title and 9 authors). "The natural indirect effect (NIE) measures how much the intervention x changes
  y indirectly, through z. It is computed by setting z to its value under the intervention x, while
  keeping everything else to its original value." SUPPORTED.
- **meng2022rome** (arXiv 2202.05262, NeurIPS 2022). Causal tracing: "The corrupted-with-restoration
  run, lets G run computations on the noisy embeddings as in the corrupted baseline, except at some
  token and layer. There, we hook G so that it is forced to output the clean state". SUPPORTED.
- **zhang2024patching** (arXiv 2309.16042, ICLR 2024). "We find logit difference a convincing metric
  for localization in language models." SUPPORTED.
- **qwen3 / qwen3coder** (arXiv 2505.09388; model card). Card: "Number of Parameters: 30.5B in total
  and 3.3B activated"; "Number of Experts: 128"; "Number of Activated Experts: 8"; "This model supports
  only non-thinking mode". The technical report does not describe the Coder variant, hence the model
  card is cited for it. SUPPORTED.
