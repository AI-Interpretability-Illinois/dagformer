# 下一步：DAGFormer 的可解释性优势

2026-09-28。研究假说与实验建议，尚未运行下面的新对比。

希望检验的主张是：**在模型已经掌握的行为上，DAGFormer 能否提供更简洁、
跨输入有效、可选择性干预的因果解释。** 性能与剪枝鲁棒性是出发点；原生
routing graph 为干预提供位置，但边权本身并不是语义标签或因果贡献。

## 已有证据决定从哪里开始

- 固定六个 copy heads 的干预能迁移到新的重复序列。两通道 gamma=1.5
  在 period 512 上提升约4.97个百分点，普通文本 NLL 增加约0.039；不同
  period 的效果不同。这提供了可检验的计算机制起点。
- 另一个固定 context edit 将 LAMBADA accuracy 从30.18%提高到32.51%，
  但 WikiText BPB 增加0.00432。该干预与 copy-head 实验是不同设置；
  尚无同等普通文本损伤下的 dense 最优干预对照。
- 300M 的 external predictor 用 position table 替代仅增加约0.00061
  NLL，而删除 local correction 增加约1.74929。这个结果约束“外置
  predictor 动态语义调度”的说法，不等于整个路由结构无作用。
- 输入逆优化能提升同模板实体—颜色绑定，但跨模板和完整 routing 系数
  移植未成功。它没有识别出可转移的绑定回路。

来源：[copy heads](../results/eval_20260917/copy_head_transfer/README.md)、
[普通评估与路由依赖](../results/eval_20260917/README.md)、
[逆优化两轮实验](../results/semantic_routing_pilot_20260928/README.md)。

## 1. 同样忠实的解释，是否更小、迁移更好

冻结两个模型，在已经掌握的重复复制、上下文值检索上找任务回路。先核对
各模型的完整任务表现，同时报告整个测试集和双方都能完成的子集，避免将
低能力模型的输出更容易模仿误当作更易解释。

一个现成起点是300M的period 128/256复制：dense与DAG分别为
96.39%/95.84%、93.08%/93.58%，已有配对区间都包含零。两者都掌握了
行为，可在新样本上比较解释复杂度；这些有限样本结果不构成能力严格等价
的证明。来源：[同输入dense对照](../results/eval_20260917/routing_dependence/dense_comparison.md)。

对 dense 和 DAG 使用同一种搜索预算、校准集和干预定义，画回路大小对
输出 KL、任务正确率、反事实 logit difference 恢复的曲线。所有 backbone
权重保持冻结；这里测的是已有计算的解释，不是剪枝后的重新训练能力。

先在共同的 head/MLP 组件粒度比较，再报告各自的原生边细节。DAG 的一条
source-state 边可能带着上游整层计算，不能将它与 dense 的细粒度边直接
等价计数；计算全部依赖，并同时报绝对组件数与占比。
完整解释还需计入predictor和correction对路由的计算依赖；若将路由固定
后只追踪来源内容，应明确报告为“给定路由下的信息流解释”。

回路只在 discovery split 选择一次，换实体、值、措辞、干扰项和检索距离
检验它是否继续有效。保留回路与删除回路均需测；存在替代回路时，必要性
可能分散在多个功能等价子图，不能要求每条边都是唯一必要路径。

若 DAG 在这些曲线上占优，可支持“更容易提取简洁、可复用的因果解释”。
单独画出一张更稀疏的 routing heatmap 不足以支持该结论。

## 2. 同样改变一个行为，是否更少影响其他行为

把已发现的读取/复制路径当作干预接口，先检验更具体的操作：改变读取哪条
上下文事实、调节重复复制强度、阻止已失效的旧值继续被复制。

例子：`A is red; B is blue; A is ...`。交换 A/B 的值、交换查询实体、加入
无关对象，要求被解释的路径跟随关系变化，而不是只提高所有颜色词的概率。
在模型实际能完成的模板上开始，再测试新模板。

与 dense 的 activation/head/edge 干预用相同数据搜索，比较目标效果对
普通文本 NLL 代价、其他检索任务损伤、无关答案变化的曲线。匹配编辑范数
不等于匹配能力损伤，因此主比较在相同 NLL 代价下进行，编辑维数另报。

如果 DAG 可以用同一个小干预跨内容控制某种计算，而且副作用更低，这将
支持“原生结构提供更选择性的控制接口”。现有 LAMBADA 改善只是起点。

## 3. 将 pruning robustness 解释成可验证的功能备份或迁移

选定同一次损伤，比较剪枝前、立即剪枝后、恢复训练后三个时刻，跟踪已
定位的检索/复制计算是否由幸存路径承担，再二次删除候选备份路径检验。
若单独删 A 或 B 都较轻，而同时删除显著破坏目标行为，且配对 activation
patching 能恢复它，才有功能冗余的因果证据。

需要区分两件事：冻结 predictor 参数后，网络仍可随输入给出不同 routing；
固定 routing tensor 才移除该输入依赖。旧 freeze-predictor 对照只表明
那批恢复结果不依赖 global predictor 参数更新，local correction 仍可训练。
对固定结构备份的检验需另用 position-conditioned constant routing，并
明确 local correction 是正常、参数冻结还是输出固定。

比较 dense 的同类损伤可以判断，这种功能备份是否与 DAG 的额外来源路径
有关。仅观察恢复后的边权重分布变化不足以证明语义功能迁移。

## EBM 式搜索如何接上

保留梯度优化输入作为发现候选行为的工具，但下一轮的因果对象扩展为边
上传递的消息。当前实现中，Q/K/V 在混合前的来源消息可写成
`m_e = (alpha_pred + delta_corr)_e * W_head * h_source`；随后仍有 norm、
attention 等非线性计算。系数移植只换乘子，没有移植被读取的信息。

在成对反事实输入上分别移植系数、来源消息及两者，测试哪个能转移查询
对应的答案变化。若消息移植有效，再学习跨样本共享的稀疏 mask，保留该
反事实效果；同时测真实任务正确率，避免仅保留颜色词总概率提升。
这也允许语义位于被读取的内容、而路由承担较稳定的读取操作。

先从已有能力清楚的300M copy/context retrieval 开始做第1和第2项的配对
验证。第3项可复用同事的剪枝轨迹，但有训练开销，应在可追踪的功能路径
确定后开展。本笔记没有启动这些作业。

## 相关方法与区别

- [Edge Pruning](https://arxiv.org/abs/2406.16778) 已在普通 Transformer 上
  用可微边剪枝寻找忠实回路；因此“可以找到稀疏回路”本身不足以构成
  DAG 的比较优势。
- [Circuit Tracing](https://www.transformer-circuits.pub/2025/attribution-graphs/methods.html)
  使用 cross-layer transcoders 与干预验证来研究特征之间的计算。DAG 的
  head/source 接线可直接干预，但不自动提供它们使用的语义特征字典。
- [Many Circuits, One Mechanism](https://arxiv.org/abs/2606.06267) 展示了
  结构不同的回路可以实现可互换的功能；因此跨输入转移与因果干预比边集合
  的重合程度更接近这里要验证的解释性。
- [Faithfulness Metrics are not Robust](https://arxiv.org/abs/2407.08734)
  指出消融定义会影响回路忠实度。对比时需统一干预，并保留实际任务表现。

以上是候选研究路线。此次针对相关工作的检查用于定位已有方法，未完成
全面新颖性检索，也未产生上述比较实验的结果。
